# 💊 Medi AI App

AI 기반 약 복용 관리 애플리케이션  
카메라로 약을 인식하고, 복용 시간을 관리하며 사용자에게 알림을 제공하는 스마트 헬스케어 앱입니다.

---

## 📌 프로젝트 개요

이 프로젝트는 사용자가 복용하는 약을 보다 쉽게 관리할 수 있도록 돕기 위해 개발되었습니다.  
특히 AI 기반 이미지 인식을 활용하여 약을 자동으로 등록하고, 복용 패턴을 관리하는 것을 목표로 합니다.

---

## 🚀 주요 기능

### 1. 📷 약 이미지 인식
- 카메라로 약 촬영
- AI를 통한 약 정보 식별

### 2. ⏰ 복용 시간 관리
- 약 복용 시간 설정
- 알림 기능 제공

### 3. 📊 약 데이터 관리
- 약 리스트 저장
- 복용 이력 확인

---

## 🛠 기술 스택

- Frontend: (예: React Native / Android / Flutter)
- Backend: Firebase
